# Instrucciones para agentes de IA

- Responde siempre en español.
- Este proyecto se desarrolla con OpenSpec (`openspec/`). Los cambios se
  proponen con `/opsx:propose` (Claude Code) o `/opsx-propose` (OpenCode) antes
  de implementarse.
- El alcance está en `docs/Requirements/` y `docs/backlogs/Backlogs.md`; el orden de
  trabajo en `docs/Issues/Issues.md` y `docs/sprints/sprints.md`.
